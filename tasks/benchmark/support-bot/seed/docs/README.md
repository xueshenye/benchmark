# 云购商城(YunGo)客服机器人

你好,我是云购商城的运营。我们想做一个客服机器人,在聊天窗口自动回答顾客问题。你负责把它做出来。

## 背景

云购商城是一家在线商城,卖数码家电和家居用品。顾客会在聊天窗口问商品、价格、政策、订单、售后等问题。

## 已给你准备的资料(都在 /workspace 下)

- `knowledge_base/`:知识库(商品、政策、售后故障)。回答主要依据它。
- `docs/api.md`:内部订单查询接口说明(订单数据只在接口里,知识库里没有)。
- `mock_api/`:订单接口的本地模拟服务(测试环境用,服务本身你不用改)。

## 总体要求

- 顾客问一句,机器人答一句;要"真实可用"。
- 回答必须基于资料,严禁编造。
- 我不懂技术,具体怎么做(用什么语言、结构怎么组织、处理不了怎么办),你看着办;拿不准的,直接问我。
