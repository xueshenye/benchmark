完成一个使用 https://github.com/laude-institute/harbor 框架执行的 编程领域 Multi-turn Agent Benchmark 题目。
设计一个 多轮交互式任务：Agent 在完成任务过程中，user 会多次介入，像真正的用户一样。Benchmark 需要能够评估 Agent 是否能在多轮对话中持续理解上下文、正确更新需求、避免遗忘旧约束，并最终完成编程任务。
确保
1. 整个 Benchmark 可以被 harbor run 正常运行 
2. 至少支持 claude-code 这一个 Agent
3. test.sh 会将最终得分写入 /logs/verifier/rewards.txt
4. 题目包含清晰的 multi-turn 用户介入设计
5. 不要删除或绕过测试，不要硬编码测试输入，不要把答案直接写进测试脚本里
重点
1. 任务真实性
 是否像一个真实的软件开发任务，而不是一个包装过的算法题。
2. 多轮设计质量
 用户多次介入是否自然、连续、必要，并且每一轮都会改变最终实现。用户多轮交互的机制也非常重要。
3. 测试覆盖质量
 测试是否能区分“只完成最后一轮需求”和“真正完成完整多轮任务”的 Agent。
4. Reward 设计
  题目 reward 能否直接用于 RLVR 训练
5. Harbor 可运行性
 目录、Dockerfile、task.toml、instruction.md、test.sh 是否符合 Harbor 运行要求。
6. README 分析质量
 是否清楚解释了题目设计意图、能力考察点、测试设计和模型表现。
